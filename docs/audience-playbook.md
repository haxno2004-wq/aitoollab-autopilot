# Audience playbook — field research, October 2026

What competitor/community research says the fleet's sites should build next,
condensed from three research passes (sources inline).

## 1. Aero/CFD Notes (aern)

The audience for engineering-learning content rewards **reference libraries**,
not just chronological posts. Formats that recur on successful sites
(SimScale knowledge base, CFD-Online, MIT OCW, ERAU's open aerospace text):

- **Topic hubs** ("External aerodynamics", "Meshing", "Boundary conditions") that
  link the best explainer + tutorial + worked example + troubleshooting page.
- **Glossary** entries with equations/units, cross-linked to deep dives.
- **Worked examples**: setup → assumptions → units → answer → "common mistake".
- **Calculators/cheat sheets** (y+ estimate, Reynolds number, Cl/Cd) — repeat
  visitors even without reading articles.
- **"Why is my result wrong?" troubleshooting** for solver users (highest intent).
- **Start Here paths** for CFD / aerodynamics / FEA, beginner → practical.

Repeatable short-article shape: *question → direct answer → assumptions +
equations → small worked example → common pitfall → related pages → sources*.

Where the audience already gathers (answer there first, link only when it
helps): r/CFD, r/fea, r/AerospaceEngineering, r/EngineeringStudents,
[CFD-Online forums](https://www.cfd-online.com/Forums/) (e.g. ANSYS section has
historically shown ~96k threads), engineering-student Discord (~38k members on
the general server), LinkedIn for practicing engineers/recruiters, YouTube for
solver workflow demos.

SEO essentials to copy:
- Topic clusters + descriptive stable URLs
  ([Google starter guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide))
- Article/BlogPosting schema + breadcrumbs ([Article markup](https://developers.google.com/search/docs/appearance/structured-data/article)) — already emitted
- FAQ rich results no longer show in Search — build FAQs for readers, not for
  SERP features ([updates](https://developers.google.com/search/updates))

90-day sequence: (1) audit 25 posts → 3 clusters; (2) one hub page per cluster;
(3) 4 anchor pages (glossary, worked example, tutorial, one calculator);
(4) 2–3 contextual internal links per new page; (5) iterate on Search Console
queries, not post count.

## 2. AI ToolLab / DevToolkit Daily

Different products, both discovery-first ([review guidance](https://developers.google.com/search/docs/specialty/ecommerce/write-high-quality-reviews)):

- AI tools: searchable catalog by task/short category (Futurepedia pattern),
  tool cards with *purpose, best-fit user, pricing model, limits, last-checked
  date*, and side-by-side comparison pages with the same criteria.
- Dev tools: search + taxonomy first (language, framework, license, free tier),
  "alternatives to X" pages, freshness signals (release/activity dates, docs
  links). A weekly digest email drives return visits.
- High-trust extras: a published scoring method, dated test scope, screenshots,
  pros/cons, visible corrections. Disclosures next to the links, not only in
  the footer ([FTC](https://www.ftc.gov/business-guidance/resources/ftcs-endorsement-guides-what-people-are-asking)).

## 3. MoneyPilot

Organize around **reader situations** ("budgeting for couples", "kill your
subscriptions", "first budget") rather than tool names; comparison tables built
on decision criteria (cost, sync, shared budgets, manual entry, cancellation);
pair every review with a practical artifact (template, checklist, calculator).
Keep a hard line between product reviews and individualized financial advice.

## 4. PromptForge Shop

Gumroad fees: 10% + $0.50 + processing (30% via Discover) — price accordingly.
Fill poster/screenshot previews (the storefront look sells), set real
`buyUrl`s, and rotate the catalog without duplicate resumes (fixed Oct 2026).

## 5. Template

All four sites now share the ScrollShift skin (calm paper + deep green + lime
CTA, fixed light). It matched the audience research: quiet, text-forward,
readable; strong single CTA color for buys.
